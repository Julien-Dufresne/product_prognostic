# product_prognostic
Product sell prognose

In this Git Hub Project, we will analyse 4 years of sales and use this data to create a ML model in order to do a prognoses of the future sales based on previous trends. 

Agenda:
1. Reviewing the data
2. Cleaning/Transform Data
3. Creating initial graphs to show trend
4. Create Baseline models
5. Create Model


Next to do:
- creating features (lag, rolling, calendar, seasonal, external features)



Models to consider: 
- Naive/ Seasonal Naive that will be the Baselines
- ARIMA/SARIMA : Trend/Autocorrelation + seasonability
- Prophet: Trend + seasonability + holidays
- Random Forest: Nonlinear relationships
- XGBoost: Strong tabular forecasting
- Catboost: Nonlinear + categorical/external features
- LSTM (Long Short-Term Memory): type of recurrent neural network): Complex sequential patterns
- GRU (Gated Recurrent Unit): Similar to LSMT
- Temporal CNN: Local temporal Patterns
- Transformer / TFT(Temporal Fusion Transformer): Complex multivariate forecasting
